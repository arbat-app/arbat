# «Арбат» — рабочее приложение риелтора

Архитектура, проверка реализуемости и план этапов. Документ обновлён 24.11.2026.

> **Изменения по решению владельца (24.11.2026):** только мобильная версия;
> две темы — светлая и тёмная; «умный» режим на GPT (OpenAI API) вместо Gemini;
> голосовой помощник Джарвис с вызовом словом «Помощник»; вход в Instagram
> кнопкой через Facebook; WhatsApp и Telegram не используются — уведомления
> только внутри приложения и через Календарь Apple; проект «Арбат»
> публикуется отдельным репозиторием GitHub и переносится на другой аккаунт.
> Ниже упоминания Gemini и Telegram — исходный вариант плана.

## 1. Общая схема

```
┌──────────────────────── Телефон / компьютер ────────────────────────┐
│  PWA «Арбат» (устанавливается на экран «Домой», работает офлайн)    │
│  ├─ Главный экран · Ежедневник · Krisha · Instagram · Помощник      │
│  ├─ IndexedDB — все данные хранятся на устройстве                   │
│  ├─ Web Speech API — распознавание и синтез речи (бесплатно)        │
│  ├─ Tesseract.js — распознавание скриншотов (бесплатно, локально)   │
│  └─ Service Worker — офлайн-режим и системные уведомления           │
└───────────────┬──────────────────────────────┬──────────────────────┘
                │ напрямую из браузера         │ этап 2
                ▼                              ▼
   Instagram Graph API (бесплатно)     Cloudflare Workers + D1 (бесплатный тариф)
   Meta Marketing API (бесплатно)      ├─ синхронизация телефон ↔ компьютер
   Gemini API (бесплатный тариф,       ├─ напоминания по расписанию → Telegram-бот
   по желанию)                         └─ подписка календаря (webcal) для iPhone
```

Технологии: чистый HTML/CSS/JavaScript (ES-модули). Сборка не нужна, платных
библиотек нет. Хостинг: GitHub Pages или Cloudflare Pages, оба бесплатные.

| Функция | Реализуемо бесплатно? | Как сделано |
|---|---|---|

Для профессионального аккаунта бесплатно. Нужно приложение на developers.facebook.com в режиме разработки: вы его владелец, проверка Meta не нужна. |

| Напоминания при закрытом приложении | ✅ Да | (1) Сразу: экспорт событий в Календарь iPhone/Mac (.ics с напоминанием), уведомления присылает сама система Apple. (2) Этап 2: бот в Telegram и подписка календаря через Cloudflare. Пока приложение открыто, работают и собственные уведомления. |
| Ежедневный отчёт, утренний план | ✅ Да | Формируются автоматически в заданное время или по кнопке. Можно скопировать или отправить. |

### Ограничения бесплатных сервисов

- **Instagram API:** около 200 запросов в час на аккаунт — с большим запасом.
  Токен действует 60 дней, приложение продлевает его само.
- **Gemini (бесплатный тариф):** ограничение запросов в минуту и в сутки. Google
  может использовать запросы бесплатного тарифа для улучшения моделей, поэтому
  не диктуйте помощнику паспортные данные клиентов. Без ключа помощник работает
  на встроенном разборщике.
- **Распознавание речи в Safari** требует интернет: распознаёт сервер Apple.
- **Уведомления на iPhone от веб-приложения** приходят, только если оно
  установлено на экран «Домой» (iOS 16.4+). Поэтому основной канал напоминаний —
  Календарь Apple и Telegram.
- **Cloudflare (этап 2):** 100 000 запросов в сутки, 5 ГБ базы — для одного
  пользователя это бесконечно много.

## 3. Модель данных (IndexedDB)

- `events`: тип, название, дата, начало и конец, адрес, клиент, телефон,
  приоритет, статус, напоминание, история переносов.
- `searches`: параметры поиска Krisha и расписание проверок.
- `listings`: объявления Krisha. Ключ — номер объявления, поэтому дубликатов нет.
- `reels` и `reports`: ролики и снимки их статистики во времени, с источником
  (API, скриншот или ручной ввод).
- `notifications`, `chat`, `settings`.

## 4. Этапы

1. **Этап 1 (готов в этой версии):** приложение целиком на устройстве.
   Главный экран, ежедневник, голосовой помощник, отчёты Instagram (API и
   скриншоты), Krisha (фильтры, ссылка поиска, кнопка-закладка, лента без
   дубликатов), уведомления, утренний и вечерний отчёты, PIN-код, резервная
   копия, офлайн-режим.
2. **Этап 2:** публикация на бесплатном хостинге (HTTPS, установка на iPhone),
   Cloudflare Worker (синхронизация, Telegram-бот, подписка календаря),
   импорт писем Krisha из почты.
3. **Этап 3:** доводка по отзывам из ежедневной работы.
