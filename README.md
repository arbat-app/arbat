# Арбат — рабочее приложение риелтора

Веб-приложение (PWA) для телефона и компьютера: ежедневник, голосовой помощник Джарвис (вызов словом «Помощник»),
объявления Krisha.kz от собственников, отчёты по Instagram Reels. Бесплатно,
на русском, работает офлайн.

Архитектура, проверка реализуемости и план этапов: [АРХИТЕКТУРА.md](АРХИТЕКТУРА.md).

## Запуск на компьютере

```bash
cd "/Users/malishka/Desktop/Arbat real" && python3 -m http.server 8765 --directory app
```

Затем откройте http://localhost:8765 в Safari или Chrome.

## На iPhone

Приложение публикуется на GitHub Pages автоматически (`.github/workflows/pages.yml`)
при каждом изменении ветки `main`. Адрес: `https://<аккаунт>.github.io/<репозиторий>/`.
На iPhone откройте адрес в Safari → «Поделиться» → «На экран „Домой“».

## Перенос на другой GitHub

В коде нет привязки к аккаунту, все пути относительные.

1. GitHub → репозиторий → Settings → General → Danger Zone → **Transfer ownership**,
   укажите новый аккаунт или организацию.
2. В новом аккаунте: Settings → Pages → Source: **GitHub Actions**.
3. Адрес приложения сменится на `https://<новый-аккаунт>.github.io/<репозиторий>/`.
   Данные на телефоне привязаны к адресу, поэтому перед переносом сохраните
   резервную копию (Настройки → Сохранить резервную копию) и восстановите её
   по новому адресу. Если вход в Instagram настроен, укажите новый домен
   в настройках приложения Meta.

## Структура

- `app/index.html`, `app/css/app.css` — оболочка и дизайн-система (оливковый, белый, чёрный; SF Pro)
- `app/js/nlp.js` — разбор русской речи: даты, время, типы дел, команды
- `app/js/assistant.js` — помощник: расписание, пересечения, свободные окна, отмена
- `app/js/events.js` — ежедневник, утренний план, вечерний отчёт
- `app/js/krisha.js` — ссылка поиска «от хозяев», кнопка «В Арбат», дубликаты
- `app/js/ig.js` — Instagram API, Marketing API, распознавание скриншотов, анализ
- `app/js/views/*` — экраны
